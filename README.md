# TSC NOTE · 나의 중국어 학습 노트

아이폰 홈 화면에 추가해서 앱처럼 쓰는 단일 HTML 중국어 학습 노트.
배포 주소: https://665ybrrhxp-wq.github.io/tsc-note/

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (기본 단어 데이터 포함). 원본: `TSC_중국어_학습앱.html` |
| `manifest.webmanifest` | 홈 화면 앱 이름·아이콘·전체화면 설정 |
| `sw.js` | 오프라인 캐시 (네트워크 우선, 실패 시 캐시) |
| `icons/` | 홈 화면 아이콘 |

## 아이폰에 설치

1. Safari로 배포 주소 열기
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면의 TSC NOTE 아이콘으로 실행 (전체화면, 오프라인 가능)

## 내용 업데이트 방법

데이터는 두 층으로 나뉜다.

- **기본 단어**: `index.html` 안의 `SEED` 배열. 이 파일을 고쳐 push하면 다음 접속 때 자동 반영.
- **내 데이터** (직접 추가한 표현, 메모, 즐겨찾기, 복습 기록): 폰 브라우저 저장소(localStorage)에만 있음. **주소가 같으면 재배포해도 유지됨.**

업데이트 경로 세 가지:

1. 폰 앱 안에서 직접 추가
2. 단어 JSON 파일을 만들어 iCloud Drive에 넣고 → 앱의 **관리 → 내용 추가** 로 가져오기 (기존 메모·기록 유지)
3. `index.html`의 SEED를 수정해서 push (같은 주소 유지 필수)

## 주의

- 내 데이터는 폰 안에만 있고 PC와 자동 동기화되지 않는다. 주기적으로 앱의 **전체 백업**을 눌러 JSON을 iCloud Drive에 보관할 것.
- 홈 화면 앱을 삭제하거나 Safari 웹사이트 데이터를 지우면 내 데이터도 사라진다.
- 배포 주소를 바꾸면(저장소 이름 변경 등) 브라우저 저장소 기준으로는 다른 사이트가 되어 내 데이터가 보이지 않는다. 바꿔야 한다면 먼저 전체 백업 → 새 주소에서 복원.
